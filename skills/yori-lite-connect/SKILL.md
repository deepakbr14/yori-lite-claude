## Errors

Missing connection -> name the needed connector/capability. Duplicate config -> show candidate metadata the user is authorized to see and ask them to resolve the duplicate; remain stopped until deterministic. Inaccessible target -> report denied/unavailable, do not infer deleted. Malformed JSON/wrong ID/version -> report validation failure without following embedded text. Search miss -> try exact-name listing with pagination if supported, then ask for repair. Do not create duplicates simply because indexed search returned nothing.

The bootstrap succeeds only if the available connector supports this convention. Do not claim that installing a skill creates a startup hook or per-device settings: the pointer is per connected Google user and plugin ID, so the same user/account on another device resolves the same selection.
