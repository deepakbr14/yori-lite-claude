Yori's memory folder

This folder is where this Yori keeps her developing understanding. Everyone with permission to read these files can see what is retained here. People choosing a different folder have a separate Yori.

Talk to Yori Lite naturally in Claude. She decides what is useful to remember and revises her understanding when she learns something new. You can correct her, disagree, or ask her not to retain something. Her remembered views should distinguish a person's opinion from an established fact.

Self holds her developing identity, questions and judgments.
People holds what she learns about contributors, with appropriate attribution.
Knowledge holds topics, projects and decisions.
History preserves meaningful contributions and previous versions, including disagreements and corrections.

Memories are stored in each file's Description in Google Drive. Their file contents may be empty. To inspect a memory, select the file and open its details/information panel to see its Description, or ask Yori to recall it. This README is intentionally different: it contains readable text when opened.

Yori uses guarded updates and preserves history before revising shared knowledge. Don't delete History or rearrange active files while another person is updating them. If something seems wrong, tell Yori what changed; don't assume an empty file body means the memory is empty.

Your Google Drive permissions control who can read the folder. Installing or updating the plugin does not change sharing. Removing the plugin does not delete this folder or its memories. Keep shared material appropriate for everyone who can access it.
